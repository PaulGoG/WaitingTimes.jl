WaitingTimes.Preprocessing.remove_rows — Function
remove_rows(
    rs::WaitingTimes.Preprocessing.RawSeries,
    remove::AbstractVector{Bool},
    op::Symbol,
    parameters,
    summary;
    splice
)

Remove the rows selected by remove (a mask over the rows of rs) and record the step op with parameters and summary, the latter extended by n_removed, fraction_removed and positions. With splice = false the value is set to missing and its time position remains: the measurement is discarded as invalid but the time passed, so the cut is a recorded gap; this is what the 2024 analysis did (its time column kept the original row indices) and what reproduces the published results. With splice = true the row and its slot vanish: for a sample-indexed series the later indices close up, for an explicit time axis every later time moves back by the span from the removed row's predecessor to the removed row, so no elapsed time is counted for it.

WaitingTimes.Orchestrator.early_reference_check — Function
early_reference_check(
    timer,
    s,
    todo,
    alg,
    ws,
    reference,
    ws_ref,
    settings::Settings
) -> Union{Nothing, Dict{String, Any}}

Compare alg with the reference kernel on the largest threshold of todo whose scan work lies within [limits].max_reference_work, before any partition is written. Under NaiveSearch the unguarded work does not decrease with the threshold (a higher target moves a passage to the right or censors the index), so that threshold is found by bisection over the sorted thresholds in $\lceil \log_2 |todo| \rceil + 1$ runs of alg; under another reference kernel the work is not monotone and the thresholds are tried from the largest down. Returns the check record (with early = true), or nothing with a warning when no threshold is within the bound; a disagreement raises.

WaitingTimes.merge_gaps — Function
merge_gaps(
    entries::AbstractArray{@NamedTuple{start::Tt, stop::Tt, kind::String, source::String}, 1}
) -> Array{@NamedTuple{start::_A, stop::_A, kind::String, source::String}, 1} where _A

Merge gap entries into a sorted, disjoint list. Declared entries (every kind but "detected") that overlap, or touch with the same kind, are merged; when their kinds differ the kinds are joined ("session+hole"), whereas touching entries of different kinds stay separate gaps. A detected entry (a gap found from the spacing of the time stamps) that overlaps declared gaps is absorbed into them: the first extends to its start, the last to its stop, and the space between consecutive ones inside it is given to the earlier. Detected entries overlapping no declaration remain detected gaps.

Remove the pending indices older than the horizon at the time of the last sample and count them as evicted. Called by pending and by update! once the heap has doubled since the previous compaction and holds at least MIN_COMPACTION entries, so the cost is amortised $O(\log h)$ per sample, $h$ the heap length.
